# Research foundations and experimental design

Primary sources inspected on 25 October 2026. This document separates published method reports from proposed FLUXATLAS experiments. Published performance figures are not FLUXATLAS measurements. The release technical report is the authority for what actually ran.

## Scientific scope

The practical starting point is a fixed-source, non-fissioning, multigroup educational transport problem with explicitly synthetic macroscopic cross sections. Synthetic material names must describe transport behavior rather than impersonate measured concrete, water, lead, or another engineering material. This makes the example reproducible without distributing evaluated nuclear data and avoids a misleading claim about real shielding performance.

OpenMC remains an independently executed numerical reference. A neural prediction, a diffusion approximation, and an analytical calculation are different evidence types. Record their provenance separately. Continuous-energy calculations and CAD transport are optional extensions after the small multigroup experiment passes its checks.

## Recommended experiment protocol

These are design recommendations, not a claim that every experiment has already been completed.

1. Define the supported parameter box, material coefficients, source distribution, geometry families, and mesh before splitting data. Draw independent configurations for training candidates, development, calibration, in-domain testing, and OOD testing. A repeated mesh cell or another source history from the same configuration does not constitute an independent geometry split.
2. Use deterministic input generation and independent solver seeds. Pair low- and high-budget fields by configuration, not by reusing a high-budget result as the low-budget input. Preserve raw results, successful-run logs, hashes, histories, batches, and actual elapsed times.
3. Train a compact positive spatial predictor in physical units or with a fixed training-only scaling. Compare a conventional supervised network, interpolation or nearest-neighbor fields, a POD/SVD model fitted only on training fields, the cheap solver alone, and a multi-fidelity correction. If the full model loses, publish that outcome.
4. For active selection, start active and random policies from the same initial configurations. Give both the same candidate pool, cheap-field information, high-budget acquisition count, history count, and stopping rule. Count every cheap candidate simulation and selected reference run. Repeat at least several acquisition seeds when feasible; one favorable path cannot establish superiority. Archive selected indices at every round.
5. Fix architecture and stopping decisions with development data, then freeze them before calibration and testing. Calibration cannot also select model hyperparameters. A pool reused for acquisition may remain training data but cannot serve as untouched test data.
6. Report per-configuration and aggregate relative L2 error, energy-group errors, integrated flux error, runtime, interval coverage and width. Include worst cases and OOD results. For pointwise relative errors, state the denominator floor and separately mark zero-count or high-relative-error reference bins.
7. Report reference noise explicitly. A useful residual diagnostic is `(prediction - reference_mean) / max(reference_SE, floor)`, with the floor disclosed. This is a diagnostic rather than a standard normal test of surrogate correctness. Correlated pixels and estimated standard errors prevent that interpretation. Use independent repeated reference seeds and increasing history counts to assess stability.
8. For calibration on noisy high-budget estimates, label coverage as coverage of an independent Monte Carlo estimate. If using `sqrt(ensemble_variance + reference_SE^2)`, state where reference SE comes from and whether it is available at inference. Model-only uncertainty must not secretly require a new high-fidelity run. To estimate whole-field coverage, calibrate the maximum standardized residual per configuration; a pooled-pixel interval supports only a different, weaker empirical coverage statement.

## Analytical verification and units

A mono-directional, purely absorbing beam supports a clean attenuation check. Across a homogeneous segment, its uncollided intensity ratio is `exp(-Sigma_t * distance)`. A mesh-average comparison must integrate that exponential over the cell instead of comparing a cell-center value with a volume average. In layered material, sum optical thicknesses along the ray. Scattering total flux generally does not obey this simple formula, and an isotropic point source also needs geometric spreading.

Use cm for length and inverse cm for macroscopic cross sections. OpenMC's raw volume-integrated flux score has dimensions cm per source particle; dividing by a volume in cm cubed gives a volume-average scalar flux normalized per source particle, cm^-2/source. Both mean and standard error need the same division. Energy-group tallies are group-integrated values, not differential values per eV unless divided by group width explicitly. Preserve group boundaries and order in exports.

[OpenMC's dose-coefficient API](https://docs.openmc.org/en/latest/pythonapi/generated/openmc.data.dose_coefficients.html) returns fluence-to-effective-dose or ambient-dose-equivalent coefficients under specified irradiation conventions. Those coefficients do not establish absorbed dose, source strength, or a dose rate by themselves. Omit dose-rate output from this educational synthetic-data release.

## Optional geometry and presentation tools

[DAGMC](https://github.com/svalinn/DAGMC) transports particles on CAD geometry. It introduces an additional geometry-preparation and dependency path, so it should remain optional until the CSG benchmark is verified. Its [license](https://github.com/svalinn/DAGMC/blob/develop/LICENSE.txt) is Simplified BSD with named subdirectory exceptions. Dependencies and geometry-preparation tools have separate terms.

[PaperVizAgent](https://github.com/google-research/papervizagent), formerly PaperBanana, is available as an Apache-2.0 repository. Its documented setup and [model configuration template](https://github.com/google-research/papervizagent/blob/main/configs/model_config.template.yaml) require external model-provider credentials or cloud configuration. That route does not fit the no-separately-billed-API constraint. Retain editable SVG or Mermaid source for conceptual architecture diagrams instead. Numerical charts must derive from exported experiment results; generative illustration is not numerical evidence.

## Licensing and claim boundaries

[OpenMC](https://github.com/openmc-dev/openmc/blob/develop/LICENSE) and [NeuralOperator](https://github.com/neuraloperator/neuraloperator/blob/main/LICENSE) use MIT licenses. Preserve notices if code is copied or bundled. Cite method inspiration even when implementations are original. Software licensing does not license an independently sourced nuclear-data library. Synthetic cross sections should have explicit project provenance and redistribution terms. Any future continuous-energy dataset requires its own provenance, license check, and download instructions.

The defensible original contribution is the specific FLUXATLAS implementation, experiment design, openly reproducible data, calibrated-analysis workflow, and interactive presentation. Claims of a new physics solver, first neutron-transport surrogate, universal uncertainty guarantee, professional shielding validation, or general active-learning superiority would require evidence beyond the modest benchmark.
