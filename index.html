Read the technical report ↗
01 / NORMALIZATION

Flux per source particle

Mesh track-length tallies are divided by cell volume. The result is a volume-averaged scalar flux in cm⁻² per source particle. No source strength or dose conversion is assumed.

02 / SUPPORTED DOMAIN

A bounded synthetic experiment

Two groups: 10⁻⁵ eV–1 keV and 1 keV–20 MeV. A collimated source mixes 1 eV and 1 MeV neutrons. One rectangular shield family, a finite x/y domain, and reflective z boundaries. Windowed shields are marked as out-of-distribution tests.

03 / UNCERTAINTY

Intervals carry assumptions

Monte Carlo standard errors describe reference sampling noise. Model intervals are calibrated as 90% simultaneous field intervals against held-out Monte Carlo estimates. Neither is a professional shielding certification.

04 / HYBRID MODEL

Known beam + learned scattering

An analytical uncollided beam is combined with a genuinely trained multi-fidelity POD neural residual model for the scattered field. The spatial surrogate uses this fixed mesh; it is not a resolution-independent neural operator.
